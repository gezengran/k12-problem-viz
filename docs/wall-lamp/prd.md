## 问题陈述

综合实践题描述一盏墙装台灯：固定支架 \(AB\)、可调灯臂 \(BC\)、竖直连接杆 \(CD\) 与灯口 \(D\)。墙 \(AE\) 竖直，地面水平。已知 \(AB=40\,\text{cm}\)，\(\angle BAE=40^\circ\)，\(BC=30\,\text{cm}\)，\(CD=5\,\text{cm}\) 且 \(CD\) 恒与地面垂直；\(\angle ABC\) 可调。题给参考三角函数值（\(\sin 40^\circ\approx 0.64\)，\(\cos 40^\circ\approx 0.77\) 等）。

两问核心不同：

1. **第(1)问**（图 2）：\(\angle ABC=90^\circ\)，求灯口 \(D\) 到墙 \(AE\) 的**水平距离**。
2. **第(2)问**（图 3）：书桌靠墙，桌面离地 \(FG=80\,\text{cm}\)；\(\angle ABC=120^\circ\)，灯口 \(D\) 在桌面上方 \(70\,\text{cm}\)，求安装点 \(A\) 离地高度 \(AG\)。

学习者容易在「\(BC\) 往哪边弯」「\(D\) 的高度与 \(A\) 的高度如何关联」上产生歧义；需要一套**可计算、可验证、可动画**的统一几何模型，并用**几何作图优先**的画面展示核心条件、目标量与约束关系，而非以坐标轴或代码变量为主线。

---

## 解决方案

采用**统一刚体链** \(A\to B\to C\to D\)：

- \(A\) 在竖直墙上；\(B\) 由 \(AB\) 长与 \(\angle BAE=40^\circ\) 唯一确定。
- \(C\) 由 \(BC\) 长与 \(\angle ABC\)（B 点**内侧角**）及**固定弯向**（恒向离开墙面一侧，与题图及实物灯臂一致）确定。
- \(D\) 在 \(C\) 正下方 \(5\,\text{cm}\)（\(CD\perp\) 地面），故 \(x_D=x_C\)。

程序内部用地面原点、墙为 \(x=0\) 的二维坐标保证数值精确；画面呈现墙、地面、书桌（第(2)问）、角度弧、垂直记号、边长与**目标括号线**，不突出坐标网格。

**交付三件套**：

| 产物 | 内容 |
|------|------|
| **静图 1** | 第(1)问：\(\angle ABC=90^\circ\)，标 \(D\) 到墙水平距离（所求） |
| **静图 2** | 第(2)问答案定格：\(\angle ABC=120^\circ\)，书桌线、\(y_D=150\,\text{cm}\) 目标线，标所求 \(AG\) |
| **Live Photo** | 第(2)问叙事动图：扫描 \(y_A\)（安装高度），实时显示 \(y_D\) 与 \(150\,\text{cm}\) 目标线的间距；重合时高亮所求 \(AG\) |

动图主产物为小红书 **Live Photo（`.pvt`）**，画幅与 `umbrella-rain` 对齐：**9:16** 竖屏画布，letterbox 至 **720×960**，复用 `solve/_common` Live 导出器。

## 实现决策

### 题面常量与参考值

- \(AB=40\,\text{cm}\)，\(\angle BAE=40^\circ\)（\(AE\) 为墙上过 \(A\) 的竖直线，\(E\) 在 \(A\) 下方）。
- \(BC=30\,\text{cm}\)；\(CD=5\,\text{cm}\)；\(CD\perp\) 地面。
- 题给近似：\(\sin 40^\circ\approx 0.64\)，\(\cos 40^\circ\approx 0.77\)，\(\tan 40^\circ\approx 0.84\)；\(\sin 80^\circ\approx 0.98\)，\(\cos 80^\circ\approx 0.17\)，\(\tan 80^\circ\approx 5.67\)。
- 第(2)问：桌面离地 \(80\,\text{cm}\)，\(D\) 在桌面上方 \(70\,\text{cm}\) \(\Rightarrow\) \(y_D=150\,\text{cm}\)（以地面为基准）。

### 统一运动学模型

- **姿态参数**：\(\angle ABC\)（度）与 \(y_A=AG\)（\(A\) 离地高度，cm）。
- **位姿计算**：由 \(A(0,y_A)\) 出发，按 \(\angle BAE\) 定 \(B\)；在 \(B\) 处按内侧角 \(\angle ABC\) 与固定弯向定 \(C\)；\(D=(x_C,\,y_C-5)\)。
- **内侧角 + 弯向**：\(\angle ABC\) 为线段 \(BA\) 与 \(BC\) 在 \(B\) 点的内侧夹角（与题图角标一致）；\(BC\) 恒向**离开墙面**一侧弯折（与第(1)问 \(90^\circ\) 时 \(C\) 比 \(B\) 更靠外、第(2)问 \(120^\circ\) 时灯臂折回下沉的题图一致）。
- **第(1)问求解**：\(\angle ABC=90^\circ\)；所求 \(x_D=x_C\)；\(y_A\) 不影响水平距离，静图可取便于构图的展示高度。
- **第(2)问求解**：\(\angle ABC=120^\circ\)；约束 \(y_D=150\)；反解 \(y_A=AG\)。

### 可视化与分镜

- **画风**：几何作图优先——竖墙、水平地面、角度弧、\(CD\perp\) 地面直角记号、已知边长标注；隐藏或弱化坐标轴刻度。
- **静图 1（第(1)问）**：灯臂 \(\angle ABC=90^\circ\)；用水平括号线或虚线强调 \(D\) 到墙距离；固定量与所求量分层标注。
- **静图 2（第(2)问答案）**：加书桌示意（高度 \(80\,\text{cm}\)）；画 \(y_D=150\,\text{cm}\) 水平目标线；\(\angle ABC=120^\circ\)；标所求 \(AG\)（与动图命中帧一致）。
- **Live Photo（第(2)问动图）**——「追目标高度」叙事：
  - 固定 \(\angle ABC=120^\circ\)、桌面线 \(80\,\text{cm}\)、目标线 \(150\,\text{cm}\)。
  - 扫描变量 \(y_A\)：从低于解到高于解（或往返），灯臂姿态实时更新。
  - 始终显示 \(D\) 当前高度 \(y_D\) 与目标线的间距（或填充带）；\(y_D\) 与 \(150\,\text{cm}\) 重合时定格/高亮，旁注所求 \(AG\)。
- **画布**：`FIG_WIDTH:FIG_HEIGHT = 9:16`，`DPI` 与 `umbrella-rain` 一致；Live 导出 letterbox 至 720×960。
- **库**：`matplotlib`（Agg）；动画逐帧渲染后交 Live 导出器。

### 模块划分（深模块优先）

| 模块 | 职责 | 对外接口（概念） |
|------|------|------------------|
| **几何内核** | 刚体链位姿、\(x_D\)、由 \(y_D\) 反解 \(y_A\)；弯向与内侧角封装在内 | `LampPose(angle_abc, y_A)` → 各点坐标；`solve_part1()` / `solve_part2()` |
| **场景预设** | 第(1)问、第(2)问答案、动图 \(y_A\) 扫描区间与帧数 | `preset_id` 或场景枚举 → 参数包 |
| **场景渲染** | 单帧：墙、地面、书桌、灯臂折线、角标、目标/约束标注 | `render_frame(pose, scene_kind, …)` |
| **导出编排** | 两张静图 PNG + 一条 Live Photo | `export_all_media(ami_dir)` |
| **Live 导出** | 帧序列 → `.pvt` | 调用 `solve/_common`；非 macOS 严格失败 |

**浅接口原则**：CLI / `run.sh` 只依赖「导出三件套」；转向与三角计算封装在几何内核内，便于单测。

**好测试标准**：验证可观察的外部行为（点位坐标、\(x_D\)、\(y_A\) 反解、\(CD\) 竖直、弯向与题图一致、画布比例、产物路径），不断言私有绘图细节。

| 模块 | 测试内容 |
|------|----------|
| **几何内核** | \(CD\) 竖直且 \(|CD|=5\)；\(|AB|=40\)，\(|BC|=30\)；\(\angle ABC=90^\circ\) 时 \(x_D\approx 48.7\,\text{cm}\)（题给 \(\sin/\cos 40^\circ\) 近似）；\(\angle ABC=120^\circ\) 且 \(y_D=150\) 时 \(AG\) 与内核反解一致；\(y_A\) 变化时第(1)问 \(x_D\) 不变 |

| **导出** | `export_all_media` 返回三件套路径；产物落在 `ami/wall-lamp/` |
