## 问题陈述

当前需要将一道伞下避雨的初中几何实践题转化为可计算、可验证、可扩展的数学模型，并通过 Python 实现求解。题目包含三个相关场景：初始姿态、手臂前伸平移、以及旋转后再调整，核心目标是计算人体被雨淋湿长度并分析无淋湿条件。

当前挑战在于题目图示关系会随场景变化（例如 `OG` 与 `NP` 从共线变为平行，再到不平行），如果采用分散建模方式，容易产生定义冲突或重复推导，影响正确性与可维护性。

面向初中生的分享场景还要求两点：一是用 Python 可视化（含动画）帮助直观理解几何变化；二是 Python 建模仅作辅助，最终讲解与书面呈现必须回归到初中数学知识（相似三角形、三角函数、平行线性质等），而非以代码或坐标系推导为主。

## 解决方案

采用统一的二维刚体几何模型：

- 人体作为固定矩形，坐标系固定于地面。
- 雨线作为固定方向直线族（向左下倾斜）。
- 伞作为可平移、可旋转的刚体（`AC` 与 `OG` 为伞上的局部几何约束）。

通过同一套“坐标变换 + 直线求交 + 区间裁剪”流程覆盖三类场景，只在姿态参数与位移参数上切换约束。输出包括：

- 第(1)问的点到地面距离
- 第(2)问的淋湿长度函数 `y=f(x)` 与不被淋湿条件区间
- 第(3)问旋转后是否可全不淋湿，以及最小调整量
- **可视化动画**：用 Python 绘图库生成竖屏（9:16）动画，展示雨线、人体、伞位姿及淋湿区间随参数变化的过程
- **初中数学讲解稿**：在数值结果校验无误后，整理与课本一致的推导路径（含作图辅助线、比例关系、角度计算），供课堂或作业分享使用

## 实现决策

- 采用二维解析几何，忽略厚度方向，符合题目“侧面近似矩形”的描述。
- 设地面为水平参考轴，人体矩形固定，人体前边界作为淋湿判定边界。
- 雨线方向统一为向左下倾斜，角度参数化为与地面的夹角 `θ`。
- 伞采用局部坐标定义几何不变量（伞宽、伞柄长度、垂直关系），再通过刚体变换映射到世界坐标。
- 三场景统一抽象：
  - 场景A：初始状态，`OG` 与 `NP` 共线。
  - 场景B：手臂前伸，`OG` 与 `NP` 平行，伞整体平移。
  - 场景C：伞发生旋转，`OG` 与 `NP` 可不平行，叠加水平调整量求最优。
- 淋湿长度统一由“过伞缘关键点的雨线”与人体前边界求交得到，并进行人体高度区间裁剪。
- 结果输出采用“符号表达 + 数值代入”双轨制：先给通式，再验证题目给定角度下的数值结果。

### 可视化与动画

- 使用 Python 可视化模块（优先 `matplotlib`，动画可用 `matplotlib.animation` 或等效方案）。
- 画布比例固定为 **9:16 竖屏**（例如宽 9 单位、高 16 单位，或像素级如 540×960），便于手机竖屏播放与课堂投屏。
- **呈现原则（几何优先）**：图中突出初中几何关系（垂直、平行、直角三角形、同图内的相似/全等、角 `θ` 等），采用试卷作图记号；**不以**坐标轴、求交算法、`y=f(x)` 或代码变量作为画面主线。程序仅负责把点线算准。
- **分场景三类信息**：每个小场景分别标明 **① 不变关系**（如 x 取何值都成立的平行/垂直/θ）、**② 同图内的几何结构**（单帧内的 Rt△、共角等）、**③ 随参数变化的量**（如 PK、EG）；**不以** x=0 与 x=0.5 并排作主图来讲「两状态三角形相似」。
- 静态图：场景 B 两张临界边界与场景 C；最大伸手虚垂线在 **x=0.7**（G 极限位置），标注 **最远 x=0.5**。详见 [umbrella-rain-viz-enhancement-feasibility.md](./umbrella-rain-viz-enhancement-feasibility.md)。
- 动画：分镜式 GIF，叙事顺序为 **不变 → 同图结构 → 参数变化**，而非参数扫描或跨状态相似对比。
- 导出格式：静态 PNG；动画 GIF（可选 MP4）。全部写入 `ami/umbrella-rain/`。

### 教学呈现：建模辅助，回归初中数学

- **定位**：Python 坐标与程序求交用于**验算、探索、动画演示**；不作为面向初中生的主讲解语言。
- **交付物分层**：
  1. **计算层**：程序给出数值与图形，确认结论正确；
  2. **讲解层**：用初中数学重述全过程——含文字步骤、标准作图、相似/三角/平行关系，与教材表述一致。
- 讲解稿中应显式对应题目小问（(1)(2)(3)），并说明“程序结果与手算一致”的核对点，增强可信度。
- 避免在分享材料中堆砌坐标公式或矩阵旋转术语；若使用程序辅助作图，图中标注仍采用题面符号（`A、C、G、P、K、θ` 等）。

## 测试决策

- 好测试标准：验证外部可观察结果（函数表达、数值解、区间结论），不耦合内部推导过程细节。
- 重点测试内容：
  - 坐标与几何不变量成立（长度、垂直/平行关系）。
  - 三个场景在统一接口下能正确切换。
  - 淋湿长度函数在边界值处连续且裁剪正确。
  - 题目给定角度（如 `60°`、`72°`）能得到稳定可复现结论。
- 增加参数化测试，覆盖不同 `θ`、前伸量和旋转量，防止单点样例“碰巧正确”。
- 可视化冒烟测试：能生成 9:16 竖屏静态图与至少一段短动画，且关键几何元素与模型坐标一致。
- 讲解稿与程序数值在题目给定数据下一致（允许四舍五入误差范围内对齐）。
