# 木板–滑块动摩擦可视化 — PRD

**case_id**：`plank-block-friction`  
**关联参考图**：`pics/截屏2026-06-04 10.53.12.png`（2015 课标 I 卷 25 题，**本题不求解该卷**）  
**推敲来源**：对话中逐项对齐的设计决策（共动视角、9:16 双屏、三预设、标注与导出策略）

---

## 问题陈述

高中物理中「木板–滑块」是经典模型，学生最容易在**动摩擦力方向**上出错：在地面惯性系里，容易误把摩擦力当成与「滑块对地速度」反向，而正确规则是**阻碍滑块相对木板接触面的滑动**——即与相对速度 \(\vec v_{\text{rel}} = \vec v_{\text{块}} - \vec v_{\text{板}}\) 反向。

在惯性系里单独画受力图，往往看不出「为什么摩擦力会指向看起来与块运动同向」；需要一种可视化，让学生**同时**看到地面系与共动系下的运动差异，并建立 \(v_{\text{rel}}\) 与 \(f\) 的方向对应关系。

本题**不要求解**参考卷中的撞墙、反撞、由 \(v\text{-}t\) 图反推 \(\mu\) 等完整考题；聚焦一个更干净的入门场景：

- \(t=0\) 时滑块与木板相对地面**均静止**；
- \(t=0^+\) 木板**突然**获得向右初速度 \(v_0\)，滑块在地面系初速仍为 0；
- 在不同摩擦参数下，观察并讲解**板–块界面动摩擦力的方向**及其随时间变化（直至共速及之后阶段）。

面向 K12 分享场景：Python 数值仿真保证物理正确，**画面以物理直觉与向量关系为主**，而非坐标推导或代码变量。

---

## 解决方案

采用一维双体模型（滑块质量 \(m\)，木板质量 \(M\)，水平面、无转动、滑块不离开木板），数值积分得到 \(v_{\text{块}}(t)\)、\(v_{\text{板}}(t)\) 及板–块界面动摩擦状态。

可视化输出为 **9:16 竖屏、上下双屏同步动画**：

| 区域 | 参考系 | 角标 | 主要标注 |
|------|--------|------|----------|
| **上屏** | 地面惯性系 | 「地面系」 | \(v_{\text{块}}\)、\(v_{\text{板}}\)（分色速度箭头） |
| **下屏** | 滑块共动（镜头锁定滑块） | 「滑块视角」 | \(v_{\text{rel}}\)、板–块界面动摩擦力 \(f\)（与 \(v_{\text{rel}}\) 颜色绑定，始终反向） |

**叙事重点**：下屏中木板、地面条纹相对滑块**反向滑动感**被适度强调，与上屏「块落后、板先走」形成对照，突出「两种看法下运动不一样，但 \(f\) 与 \(v_{\text{rel}}\) 的关系不变」。

提供 **3 个预设场景**（固定参数组合，各导出一条动画），共速瞬间**高亮**（\(v_{\text{rel}}=0\)，动摩擦消失），并按预设决定共速后的续播时长。

**导出策略**：v1 以 **MP4** 为主产物（跨平台、便于开发与 CI）；在 macOS 上通过 `run.sh` **可选**打包为小红书 **Live Photo（`.pvt`）**，复用 `solve/_common` 已有 Live 导出能力。

## 用户故事

1. 作为高中生，我希望同时看到地面系和滑块视角下的运动，以便理解为什么动摩擦方向不能只看「块对地速度」。
2. 作为学习者，我希望画面上直接标出 \(v_{\text{rel}}\) 和 \(f\)，且二者颜色一致、方向相反，以便记住「阻碍相对滑动」。

## 实现决策

### 物理模型

- **维度**：一维水平；忽略 air drag、绳、弹簧、墙与碰撞。
- **初值**：\(t=0\) 时 \(x_{\text{块}}=x_{\text{板}}=0\)（或等价地滑块在板左端），\(v_{\text{块}}(0)=v_{\text{板}}(0)=0\)。
- **初速度施加**：\(t=0^+\) 仅木板获得 \(v_{\text{板}}=v_0\)（滑块对地速度仍为 0）；不建模「人推块」等额外冲量。
- **板–块界面**：
  - 当 \(|v_{\text{块}}-v_{\text{板}}|>\varepsilon\) 时，动摩擦力大小 \(f=\mu_2 m g\)，方向与 \((v_{\text{块}}-v_{\text{板}})\) 反向；
  - 共速后（\(|v_{\text{rel}}|\le\varepsilon\)），板–块界面**无动摩擦**；块–板之间由静摩擦维持共速（本可视化不在共速后继续画板–块 \(f\)，除非未来扩展）。
- **板–地界面**：当 \(\mu_1>0\) 且木板相对地面运动时，动摩擦力 \(f_1=\mu_1 M g\)（或按 \(M+m\) 等效约定，实现时选定一种并在测试中固定），方向与 \(v_{\text{板}}\) 反向；\(\mu_1=0\) 时无地面摩擦。
- **默认常量**：\(g=10\,\text{m/s}^2\)，\(v_0=4\,\text{m/s}\)，\(M=15m\)。

### 三个预设场景

| 预设 ID | 叙事 | \(\mu_1\)（板–地） | \(\mu_2\)（块–板） | 共速后续播 |
|---------|------|-------------------|-------------------|------------|
| **preset-1** | 基准：块落后、\(f\) 向前 | 0 | 0.2 | **1 s** |
| **preset-2** | 强耦合：很快共速 | 0 | 0.6 | **1 s** |
| **preset-3** | 地面耗散：共速后板–块一起减速 | 0.15 | 0.2 | **2 s** |

- 动画总时长 = **到达共速时刻** + 上表续播时长（三预设共速时刻不同，**不**强行拉齐绝对时间轴长度）。
- **preset-3 共速后**：上屏可补充**地面摩擦力**箭头；板–块界面不再绘制 \(f\)，与 preset-1/2 的「共速后无动摩擦」叙事一致。

### 可视化与分镜

- **布局**：9:16 竖屏；**上：地面系**，**下：滑块视角（共动）**；每屏一角一行角标（「地面系」「滑块视角」），不单独占第三行大标题栏。
- **共动实现（运动学）**：下屏世界变换使滑块固定在画面参考位置；**不**默认绘制惯性力/科氏力（非惯性系完整版不在 v1 范围）。
- **标注方案（标准 B）**：
  - 上屏：\(v_{\text{块}}\)、\(v_{\text{板}}\) 分色箭头；
  - 下屏：\(v_{\text{rel}}\) 与 \(f\) 箭头，**共用强调色**，\(f \perp\) 接触面，与 \(v_{\text{rel}}\) 反向；
  - 全动画共用图例说明颜色含义。
- **共速高亮**：检测到 \(v_{\text{rel}}\to 0\) 时，短促视觉提示（如字幕「\(v_{\text{rel}}=0\) → 动摩擦消失」或等价闪烁/定格），然后进入续播段落。
- **下屏增强**：木板表观相对运动、地面背景条纹反向流动，适度夸张以强化「与上屏不同」的观感，但不得歪曲 \(v_{\text{rel}}\) 与 \(f\) 的方向关系。
- **画布与库**：优先 `matplotlib`；竖屏比例复用 `solve/_common` 中既有 portrait 约定（与 `umbrella-rain`、`compound-growth` 一致）。

### 模块划分（深模块优先）

| 模块 | 职责 | 对外接口（概念） |
|------|------|------------------|
| **仿真内核** | 1D 动力学积分、摩擦分段、共速事件检测 | 输入 \((m,M,\mu_1,\mu_2,v_0,g)\) 与时长策略 → 输出时间序列状态（位置、速度、\(v_{\text{rel}}\)、是否接触动摩擦、地面摩擦有无） |
| **预设注册** | 三预设参数与续播策略 | `preset_id` → 仿真配置 + 叙事标题/字幕 |
| **双屏渲染** | 单帧上下子图：几何（块、板、地面）、速度/力向量、角标、共速高亮 | 输入某一时刻状态 + 样式配置 → 一帧图像 |
| **动画导出** | 按共速+续播生成帧序列，写 MP4 | 输入 `preset_id`、输出 stem → MP4 路径 |
| **Live 导出（可选）** | macOS 上 MP4/帧 → `.pvt` | 调用 `solve/_common` Live Photo 导出器；失败严格报错 |

**浅接口原则**：`viz` / CLI 只依赖「预设 id + 导出」；摩擦公式与事件检测封装在仿真内核内，便于单测。

## 测试决策

**好测试标准**：验证可观察的外部行为（速度演化、共速时刻、摩擦方向与 \(v_{\text{rel}}\) 符号关系、动画可生成），不断言内部积分步长或私有绘图细节。

| 模块 | 测试内容 | 先例 |
|------|----------|------|
| **仿真内核** | ① \(\mu_1=0,\mu_2=0.2\) 下共速时刻在合理范围；② 共速后 \(|v_{\text{rel}}|\) 保持近零；③ 有相对滑动时 \(f\) 与 \(\operatorname{sgn}(v_{\text{块}}-v_{\text{板}})\) 相反；④ preset-2 共速早于 preset-1；⑤ preset-3 共速后 \(v_{\text{板}}\) 单调减小 | 类似 `compound-growth` 的 `test_math_model.py` |
| **预设注册** | 三预设参数与续播时长配置只读一致 | `umbrella-rain` 的 constants/scenes 测法 |
| **渲染/导出** | 生成至少一帧/一段短 MP4；画布宽高比接近 9:16；双屏角标存在 | `umbrella-rain` 的 `test_viz.py` 冒烟 |
| **路径** | 导出路径落在 `ami/plank-block-friction/` | `solve/_common/tests/test_paths` 模式 |

- 允许数值积分带来的小误差；共速检测使用明确 \(\varepsilon\) 并在测试中固定。
- Live Photo 打包：非 macOS 调用应失败并返回可读错误（若 v1 已接 Live 路径）。

## 不在范围内

- 不求解 2015 课标 I 卷 25 题（撞墙、\(v\text{-}t\) 图反推 \(\mu_1,\mu_2\)、最小板长、最终板–墙距离等）。
- 不实现滑块视角下的**惯性力/科氏力**完整非惯性系分析（v1 仅运动学共动 + 真实接触力 \(f\)）。
- 不处理滑块离板、板离地、二维、转动、弹性碰撞。
- 不做运行时交互滑块（拖 \(\mu\) 实时预览）；参数变更通过预设或脚本参数重导出。
- 不追求电影级渲染；以向量关系清晰为准。
- GIF 不作为 v1 必交付物；不以 GIF 作为小红书主发布链路。

## 其他说明

### 已对齐设计决策清单（推敲摘要）

1. **主视角**：运动学共动（镜头跟滑块），突出与惯性系观感不同；**不**默认上惯性力图解。
2. **布局**：9:16 **上下双屏**同步；**上惯性 / 下共动**；角标「地面系」「滑块视角」。
3. **场景组织**：**3 个固定预设**（非连续扫参、非交互 UI）。
4. **标注**：标准 B（上 \(v_{\text{块}},v_{\text{板}}\)；下 \(v_{\text{rel}},f\)；颜色绑定 + 共速高亮）。
5. **停点**：preset-1/2 共速后再播 **1 s**；preset-3 共速后再播 **2 s**。
6. **参数**：\(v_0=4\,\text{m/s}\)，\(M=15m\)，\(g=10\)；\(\mu\) 组合见上表。
7. **导出**：**MP4 为主**；macOS 可选 **Live Photo（C 方案）**。

### 后续可扩展（非 v1）
