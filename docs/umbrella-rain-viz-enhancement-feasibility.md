## 1. 核心定位：几何作图优先，程序退居幕后

| 层级 | 角色 | 图中是否出现 |
|------|------|----------------|
| **讲解层（主）** | 垂直、平行、Rt△、同图内的相似/全等、角 `θ`、不变/可变标注 | ✅ 是 |

程序只负责 **把点线算准**；画面是「试卷作图 + 关系强调」。

## 2. 分场景的三类几何信息（制图逻辑）

每个小场景（图1 / 图2 / 图3）在出图时先列清单，再决定画哪几张 PNG：

| 类型 | 含义 | 画法建议 | 例（图2，手臂前伸 x） |
|------|------|----------|------------------------|
| **① 不变关系** | 在本场景允许范围内，**无论 x（或其它参数）取何值都成立** | 实线 + 角标/平行/垂直记号；图角注「不随 x 改变」 | 雨线互相平行且与地面成 θ；`OG ∥ NP`；`OG ⟂ AC`；伞面水平；`|AC|=1`、`|OG|=0.45`；G 离地 1.35 m |
| **② 同图内的几何结构** | **在任意一帧图形里**，由题意作出的辅助线围成的三角形/角关系 | 填充 Rt△、标对应角、写「相似」或「全等」时必须有 **同一帧内的两组图形** | 过 C 的雨线与水平线、竖线 NP 围成 **Rt△**（竖边 PK、水平直角边 0.5 m）；若再作出过 A 的雨线，可与前者 **共用角 θ** 讨论角相等（进而得相似，仍在 **一张图内** 完成） |
| **③ 随参数变化的量** | 本场景内会随 x 等改变的 **线段长度或位置** | 双色括号线或虚线框；与 ① 对照，避免误当成「全等」 | `EG = x` 变长；C 水平后移；**PK 变短**（三角形竖边变短，但 ② 中 Rt△ 的 **角与水平直角边 0.5 m 不变**） |

**明确不做**：把 x=0 与 x=0.5 画成左右两图，主标题写「两个状态三角形相似」——那会把「参数变化」误讲成「跨状态相似」，偏离初中作图习惯。

**动图可以** 演示 x 从 0→0.5，但旁白逻辑应是：「**平行、垂直、θ 一直不变** → **只有 PK、C 位置在变**」，而不是「左右两个三角形相似」。

## 3. 视觉语法（全系列复用）

| 关系类型 | 画法 | 用于 |
|----------|------|------|
| **垂直** | 直角方框 | `OG ⟂ AC`；图3 `AC ⟂` 雨线 |
| **平行** | 双箭头 / 平行雨箭 | 雨线族；`OG ∥ NP` |
| **相等的角** | 同色角弧 | 雨线与地面均为 θ |
| **直角三角形** | 浅色填充 + 直角标记 + 边长 | 图1、图2 求 PK（**单帧**） |
| **相似 / 全等** | 仅当 **同图内** 两个（或多个）图形对应角相等时标 | 例如同一帧内：小 Rt△ 与含 A 的三角形 **共角 θ** → 标对应角，再写相似；**禁止**跨 x=0 / x=0.5 两帧作主图 |
| **不变 / 可变** | 图例：实线「不变」、橙色「随 x 变」 | 图2、图3 总览图 |
| **雨水** | 平行箭头束（向左下） | 全场景 |

**不出现**：坐标轴、`(x,y)`、主标题 `y=f(x)`、代码变量名。

| 类型 | 内容 |
|------|------|
| **不变** | θ=60°；雨线平行；G 离地高度不变；`|OG|`、`|AC|` 不变；旋转后恒有 **`AC ⟂` 雨线** |
| **同图结构** | 旋转后的 Rt△ 或「垂直 + 三角」组合（按一帧画出）；绕 G 旋转为 **图形变换**，不是参数 x 的扫描 |
| **可变** | `EG`；C 位置；PK |
