# 雨天撑伞几何题 — 任务拆分

**父级文档**：[umbrella-rain-geometry-prd.md](./umbrella-rain-geometry-prd.md)

**开发方式**：测试驱动开发（TDD），纵向 tracer bullet（一次一条测试 → 最少实现 → 通过 → 再写下一条）。禁止「先写完全部测试再写完全部实现」的横向切片。

**本题 case_id**：`umbrella-rain`  
**目录约定**：源代码与测试在 `solve/umbrella-rain/`；动画与图片导出到 `ami/umbrella-rain/`。后续新题在 `solve/<case_id>/`、`ami/<case_id>/` 下各建独立目录（见 PRD）。

---

## TDD 工作约定

每条任务内按以下循环执行，完成后再进入下一条任务：

1. **红**：写一条描述**可观察行为**的测试（只走公共 API），运行并确认失败。
2. **绿**：写最少产品代码使该测试通过。
3. **重构**（可选）：在全部相关测试仍绿的前提下整理结构；禁止在仍为红时重构。

测试风格：

- 使用 `pytest`；测试文件放在 `solve/umbrella-rain/tests/`。
- 测行为（数值、区间、文件是否生成），不测私有函数名或内部数据结构细节。
- 题目给定数据作为**黄金用例**（如 `θ=72°` 时 `PK≈0.26`、`C` 离地 `1.8`）。

运行命令（与项目规则一致）：

```bash
conda run -n math python -m pytest solve/umbrella-rain/tests -q
conda run -n math python -m ruff check solve/umbrella-rain
```

## 任务 1：人体固定与雨线求交（淋湿长度核心）

**类型**：AFK  
**阻塞于**：0  
**覆盖用户故事**：1, 3

### 要做什么

实现最小可用的「向左下倾斜雨线 + 人体前边界竖线」求交，得到淋湿长度 `PK`（对 `[0, 人体高]` 裁剪）。此切片不引入伞旋转，可先用给定的伞缘点 `C` 坐标驱动。

### TDD 步骤

| 步骤 | 红 | 绿 |
|------|----|----|
| 1.1 | 前边界 `x=0.2` 上，给定 `C=(0.7, 1.8)`、`θ=72°`，`wet_length_pk()` 接近 `0.26`（容差与题面一致） | `solve/umbrella-rain/geometry.py` |
| 1.2 | `y_K <= 0` 时淋湿长度为 0 | 裁剪逻辑 |
| 1.3 | `y_K >= 1.6` 时淋湿长度为 1.6 | 上界裁剪 |
| 1.4 | `θ=60°`、`C=(0.7, 1.8)` 与手算/题面中间值一致 | 参数化或第二条黄金用例 |

### 验收标准

- [ ] 测试描述「给定 C 与 θ 时的 PK」，不绑定内部矩阵实现
- [ ] 雨线方向与 PRD 一致（向左下倾斜，与地面夹角 `θ`）
- [ ] 重构后测试仍绿

## 任务 2：伞刚体局部几何与世界坐标

**类型**：AFK  
**阻塞于**：1  
**覆盖用户故事**：2, 3

### 要做什么

用局部坐标（`A,C,O,G` 相对伞心/伞柄）+ 平移 `(t_x, t_y)` + 旋转角 `φ` 映射到世界坐标；保证 `|AC|=1`、`|OG|=0.45`、`OG ⟂ AC` 恒成立。

### TDD 步骤

| 步骤 | 红 | 绿 |
|------|----|----|
| 2.1 | `φ=0`、平移使 `G=(0.2, 1.35)` 时，`O.y=1.8`，`C.y=1.8` | `UmbrellaPose` 或等价 API |
| 2.2 | 场景 A：`x=0` 时 `OG` 与 `NP` 共线（同 x=0.2） | 默认姿态 |
| 2.3 | 场景 B：`φ=0`，水平前伸 `x` 时 `G=(0.2+x, 1.35)`，`OG` 竖直（与 `NP` 平行） | `extend_arm(x)` |
| 2.4 | 场景 C：给定 `φ=-30°`（或 `AC⊥` 雨线推导角），`C` 坐标满足旋转约束 | `rotate(phi)` |
| 2.5 | `wet_length_pk` 接受 `UmbrellaPose` + `θ`，不再手写 `C` | 与任务 1 集成 |

### 验收标准

- [ ] 不变量在任意 `(x, φ)` 下由测试保证
- [ ] 公共 API 足以支撑三场景，无需为每场景复制求交代码

## 任务 4：场景 B — `y=f(x)` 与头部不淋区间

**类型**：AFK  
**阻塞于**：2  
**覆盖用户故事**：2, 3

### 要做什么

`θ=60°`，手臂前伸 `x∈[0, 0.5]`：`PK = y(x)`；判断是否存在 `x` 使头部（`y=1.6`）不被淋湿，并给出 `x` 的可行范围结论。

### TDD 步骤

| 步骤 | 红 | 绿 |
|------|----|----|
| 4.1 | `x=0` 时 `y(0)` 与推导值一致 | `scene_b(x)` |
| 4.2 | `y(x)` 随 `x` 增大而减小（或单调性断言） | 数值采样或导数符号 |
| 4.3 | `head_dry_range()`：在 `x∈[0,0.5]` 内最大淋湿高度 `< 1.6` 或给出「无解」结论 | 与 PRD 推论一致（图2 下全干需 `x>0.5` 量级） |
| 4.4 | 参数化：`x=0.25` 单点黄金值 | 防止回归 |

### 验收标准

- [ ] 输出可打印的 `y=f(x)` 说明（函数或分段描述）
- [ ] 「头部不淋」结论与手算一致，测试即规格

## 任务 5：场景 C — 旋转后全干与最小前伸量

**类型**：AFK  
**阻塞于**：2  
**覆盖用户故事**：2, 3

### 要做什么

在场景 B 条件基础上，伞绕 `G` 顺时针转至 `AC⊥` 雨线（`G` 高度不变）；判断是否存在前伸量使 `PK=0`；若存在，求最小 `EG`。

### TDD 步骤

| 步骤 | 红 | 绿 |
|------|----|----|
| 5.1 | `rotate_until_ac_perpendicular_rain()` 满足 `AC⊥` 雨线（角度或点积断言） | 场景 C 姿态构造 |
| 5.2 | 存在 `e` 使 `wet_length(scene_c(e)) == 0` 或断言不存在 | 求解/扫描 |
| 5.3 | 若存在，`min_eg_for_dry()` 与手算最小值一致（容差内） | 一维优化或解析解 |
| 5.4 | `e` 超出 `[0, 0.5]` 时的边界行为明确（裁剪或报无解） | 文档化行为 |

### 验收标准

- [ ] 场景 C 与 B 共用同一 `wet_length` 入口
- [ ] 结论（有/无最小 `EG`）有测试锁定
