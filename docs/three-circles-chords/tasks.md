## TDD 工作约定

每条任务内按以下循环执行，完成后再进入下一条任务：

1. **红**：写一条描述**可观察行为**的测试（只走公共 API），运行并确认失败。
2. **绿**：写最少产品代码使该测试通过。
3. **重构**（可选）：在全部相关测试仍绿的前提下整理结构；禁止在仍为红时重构。

测试风格：

- 使用 `pytest`；测试放在 `solve/three-circles-chords/tests/`。
- 测行为（弦长、等长/等和、可行域、帧是否生成、画布比例 3:4、`.pvt` 契约），不测私有函数名或绘图美学细节。
- 浮点相等判定使用固定 \(\varepsilon\)，在首条相关测试中写死。

运行命令（与项目规则一致）：

```bash
export PYTHONPATH="solve/_common:solve/three-circles-chords"
conda run -n math python -m pytest solve/three-circles-chords/tests -q
conda run -n math python -m ruff check solve/three-circles-chords
```

## 任务 1：圆–直线交点与弦长几何内核

**类型**：AFK  
**阻塞于**：0  
**覆盖用户故事**：8

### 要做什么

实现端到端几何内核：直线 \(l:y=kx+b\)（及垂线等数值边界）与单位圆求交；输出每圆弦端点、弦长 \(s_i\)、相切/双交状态；内部可算 \(\sum s_i\)，**不向画面暴露数字**。

### TDD 步骤

| 步骤 | 红 | 绿 |
|------|----|----|
| 1.1 | 已知 \((k,b)\) 下三弦长与手算/对称性一致（选 1～2 个黄金 \((k,b)\)） | `geometry.py` 或等价公共 API |
| 1.2 | 直线与某圆相切时该圆弦长 \(\to 0\) | 相切判定 |
| 1.3 | 直线过圆心时该圆弦长 \(\to 2\) | 直径情形 |
| 1.4 | 三圆均双交时，公共 API 返回 3 条有效弦 | 状态枚举 |
| 1.5 | \(b=0\) 时 \(\sum s_i\) 在某 \(k^\*\) 处为 \(b=0\) 约束下的极大（容差内，\(k^\*\) 由测试锁定区间） | 为 D 段预设奠基 |

### 验收标准

- [ ] 公共 API 为「\((k,b)\) in → 弦几何 out」，不暴露求交算法内部细节
- [ ] 不实现画面渲染
- [ ] 允许浮点容差，\(\varepsilon\) 在测试中写明

## 任务 2：\(b\) 信封与三圆双交可行域

**类型**：AFK  
**阻塞于**：1  
**覆盖用户故事**：1, 8

### 要做什么

对固定 \(k\)，计算使三圆**均交于两点**的 \(b\) 区间 \([b_{\min}(k), b_{\max}(k)]\)（相切为边界）；提供沿信封线采样或扫描的辅助 API，供前奏镜 2 与 C 段素材使用。

### TDD 步骤

| 步骤 | 红 | 绿 |
|------|----|----|
| 2.1 | 固定 \(k\) 时 \(b_{\min} < b_{\max}\) 且边界处恰有一圆相切 | `envelope.py` 或几何内核扩展 |
| 2.2 | \(b_{\min}\) 处相切圆弦长 \(< \varepsilon\) | 与任务 1 集成 |
| 2.3 | 区间内的样本 \(b\) 均满足三圆双交 | 可行域校验 |
| 2.4 | 沿 \([b_{\min}, b_{\max}]\) 均匀取 \(n\) 个点不越界 | 扫描辅助 |

### 验收标准

- [ ] 扫描轨迹不越出三圆双交可行域
- [ ] 不依赖 matplotlib
- [ ] 为任务 5 前奏镜 2 提供可调用接口
