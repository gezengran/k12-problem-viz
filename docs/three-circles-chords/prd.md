**case_id**：`three-circles-chords`  
**关联参考图**：`pics/20260609154748_33_7.png`（数学试题第 3 页第 11 题）  
**核心理念**：`core.md` — 将抽象知识转化为可见动画  
**推敲来源**：对话中逐项对齐的选题、分镜、弦长呈现、选项索引叙事与 Live Photo 发布策略

---

## 问题陈述

高考多选题第 11 题涉及三个单位圆与动直线 \(l:y=kx+b\) 的弦长关系。题面给出圆 \(C_1,C_2,C_3\) 及弦长 \(s_1,s_2,s_3\)，四个选项分别讨论：\(k\) 的取值范围、使 \(s_1=s_2=s_3\) 的直线条数、使 \(s_1+s_2+s_3=3\) 的直线条数、以及 \(b=0\) 时弦长之和的最大值。

学习者和内容创作者在阅读选项时，往往难以把**文字条件**迅速对应到**具体几何画面**：哪条线代表选项 B？「超过 3 条」在图上长什么样？\(b=0\) 时的「最大总长」对应什么姿态？纯手算或静态截图难以在有限时间内建立这种映射。

面向小红书分享场景：需要一条 **3:4 竖屏 Live Photo** 动画，核心目标**不是解题、不是公布答案**，而是让观众**快速找到各选项所描述的几何情形**——把抽象的选项文字变成可辨认的动画场景。动画应突出**三色弦长随 \(k,b\) 的变化**，而非弦长数值读数或坐标推导。

---

## 解决方案

采用解析几何精确计算直线与三圆的交点及弦长，驱动 **matplotlib** 分镜动画。三圆配置与题面一致：

- \(C_1:(x+1)^2+y^2=1\)（圆心 \((-1,0)\)）
- \(C_2:(x-1)^2+y^2=1\)（圆心 \((1,0)\)）
- \(C_3:x^2+(y-\sqrt{3})^2=1\)（圆心 \((0,\sqrt{3})\)）

画面语言：

- 三个圆用浅色描边；直线 \(l\) 用浅色虚线表示。
- 圆内两交点之间的**弦**为画面主角：\(C_1/C_2/C_3\) 各一**加粗分色线段**，弦长通过**线段长短**直观呈现；**不显示** \(s_1,s_2,s_3\) 数值标注。
- 段首角标标注选项字母 **A / B / C / D**；动画**不判定**哪项正确，悬念留给封面文案与评论区。

成片结构为 **前奏 + 四段式正文**（合成**一条** Live Photo）：

| 段落 | 时长（约） | 内容 |
|------|------------|------|
| **前奏** | ~10 s | **镜 1**：固定 \(b=b_0\)，\(k\) 连续扫描 → 展示弦随斜率变化；**镜 2**：固定 \(k=k_0\)，\(b\) 连续扫描 → 展示弦随平移变化 |
| **A 段** | 3～5 s | 快切多个差别明显的 \(k\)（\(b\) 固定），三圆均有弦 → 对应「\(k\) 可取任意实数」的情形空间 |
| **B 段** | 3～5 s | 定格或慢闪：**三色弦视觉等长** → 对应「\(s_1=s_2=s_3\)」的对称情形 |
| **C 段** | 3～5 s | 快切 4～5 组不同 \((k,b)\)，直线姿态明显不同；辅以**极淡折线**将三色弦首尾相连，各帧折线**总长度一致** → 对应「\(s_1+s_2+s_3=3\)」且**不止一条**直线 |
| **D 段** | 3～5 s | 固定 \(b=0\)（直线过原点），\(k\) 扫描并停在弦长之和的**视觉峰值**姿态 → 对应「\(b=0\) 时 \(\sum s_i\) 最大」的情形 |

**导出策略**：主产物为小红书 **Live Photo（`.pvt`）**；在 macOS 上通过 `solve/_common` 已有 Live 导出能力打包；开发调试期可保留中间帧/视频。

## 用户故事

1. 作为高中生，我希望在动图中看到直线倾斜和平移时三条弦如何联动变化，以便把 \(k,b\) 与弦长联系起来。
2. 作为刷题者，我希望每个选项字母出现时，画面上就是该选项描述的那种典型几何情形，以便快速对号入座而非先完整解题。
3. 作为学习者，我希望选项 B 段能一眼看出「三色弦一样长」，以便理解 \(s_1=s_2=s_3\) 在图上意味着什么。
4. 作为学习者，我希望选项 C 段在直线各不相同的同时，能看出「总长同一种状态」且出现多次，以便理解「超过 3 条」的含义。
5. 作为学习者，我希望选项 D 段明确是过原点的直线，并在某一倾角下三色弦同时达到最长感，以便理解 \(b=0\) 下的极值情形。
6. 作为内容创作者，我希望得到一条 3:4 竖屏 Live Photo，以便 AirDrop 到 iPhone 后按小红书实况链路发布。
7. 作为分享者，我希望动画不剧透正确答案，以便评论区与文案保留讨论空间。
8. 作为项目维护者，我希望几何计算与分镜渲染分层、可单测，以便调整各段参数而不破坏导出路径约定。
9. 作为协作者，我希望产物只写入本题 `ami/` 目录，以便与仓库多题布局一致。

## 实现决策

### 题面与计算模型

- **直线**：\(l: y=kx+b\)；实现中可用等价一般式处理垂线等数值边界。
- **弦长**：对每一圆，若直线与圆交于两点，弦长为两交点距离；若相切则弦长为 0；实现内部可计算精确值用于选参与断言，**画面不展示数字**。
- **可行域**：「三圆均交于两点」的 \((k,b)\) 集合；可推导每固定 \(k\) 下使某圆相切的 \(b_{\min}(k), b_{\max}(k)\) 信封，供前奏镜 2、C 段素材与 D 段扫描使用。
- **选项场景参数**：为 A/B/C/D 各段预选一组或多组 \((k,b)\)（及 C 段的多帧列表），由几何内核校验满足题设相关条件（如 B 段三色弦等长、C 段 \(\sum s_i\) 一致、D 段 \(b=0\) 且总和极大）。参数表可配置，不硬编码在渲染层。

### 可视化与分镜

- **画布**：3:4 竖屏；复用仓库既有 portrait 约定（与 `umbrella-rain`、`compound-growth` 一致）。
- **几何优先**：图中以三圆、弦、直线为主；坐标轴弱化或省略；不以求交算法或公式作为画面主线。
- **弦的绘制**：仅绘制圆内两交点间线段；线宽与颜色为全片最主要视觉层次。
- **直线**：全片统一浅色虚线，避免抢弦的视觉焦点。
- **选项 C 辅助线**：用**极淡色**折线顺序连接三弦端点（实现时固定连接顺序并在测试中锁定）；折线在各快切帧间**总长度一致**；折线视觉权重低于三色弦。C 段快切节奏与折线淡化程度需 **HITL 人工验收**（见 [tasks.md](./tasks.md) 任务 8）。
- **角标**：每段起始处显示选项字母 **A/B/C/D**；前奏可不标选项字母，或标「\(k\)」「\(b\)」等极简提示（实现时二选一，默认仅正文四段打字母角标）。
- **前奏参数**：\(b_0,k_0\) 选取应使镜 1、镜 2 中三色弦**明显不对称**，便于看出单参数扫描效果；且不与正文四段主帧重复（具体数值在实现阶段由预设表给出）。
- **库**：优先 `matplotlib`；动画逐帧渲染后交 Live 导出器。

### 模块划分（深模块优先）

| 模块 | 职责 | 对外接口（概念） |
|------|------|------------------|
| **几何内核** | 圆–直线交点、弦长、相切判定、\(b\) 信封 \([b_{\min}(k),b_{\max}(k)]\) | 输入圆心与半径、\((k,b)\) → 输出各弦端点与弦长（内部）；相切/双交状态 |
| **选项场景注册** | A/B/C/D 及前奏的 \((k,b)\) 序列、时长、转场方式 | `segment_id` → 时间轴片段描述（扫描 / 定格 / 快切帧列表） |
| **场景渲染** | 单帧：三圆、虚线、三色弦、可选淡折线、角标 | 输入 \((k,b)\) + 样式配置 → 一帧图像 |
| **分镜时间轴** | 拼接前奏 + 四段；控制每段帧数与 easing | 输入场景注册表 → 帧生成器或帧列表 |
| **Live 导出** | 帧序列 → `.pvt` | 调用 `solve/_common` Live Photo 导出器；非 macOS 严格失败 |

**浅接口原则**：CLI / `run.sh` 只依赖「导出整条 Live」；弦长公式与可行域封装在几何内核内，便于单测。

## 测试决策

**好测试标准**：验证可观察的外部行为（弦长关系、等长/等和条件、可行域边界、帧可生成、画布比例、Live 导出契约），不断言私有绘图细节或具体帧美学。

| 模块 | 测试内容 | 先例 |
|------|----------|------|
| **几何内核** | ① 已知 \((k,b)\) 下弦长与手算/对称性一致；② 相切时弦长 → 0；③ 过圆心时弦长 → 2；④ B 段预设参数下 \(s_1=s_2=s_2\)（数值相等）；⑤ C 段预设各帧 \(\sum s_i\) 相等；⑥ D 段 \(b=0\) 且总和为 \(b=0\) 约束下的极大 | 类似 `compound-growth` 的 `test_math_model.py` |
| **信封 / 可行域** | 固定 \(k\) 下 \(b_{\min},b_{\max}\) 与相切条件一致；扫描轨迹不越界 | `umbrella-rain` 边界区间测法 |
| **选项场景注册** | 四段 + 前奏配置只读一致；C 段快切帧数 ≥ 4 | `plank-block-friction` 预设注册测法 |
| **渲染 / 导出** | 生成至少一帧；宽高比接近 3:4；三色弦元素存在；C 段可选淡折线 | `umbrella-rain` 的 `test_viz.py` 冒烟 |
| **路径** | 导出落在 `ami/three-circles-chords/` | `solve/_common/tests/test_paths` 模式 |
| **Live 导出** | macOS 可产出 `.pvt`；非 macOS 调用失败且信息可读 | `solve/_common/tests/test_live_photo_export.py` |

- 允许浮点误差；相等判定使用明确 \(\varepsilon\) 并在测试中固定。
- 不测试具体角标字体、颜色色值等纯审美选择，除非影响可读性契约。

## 其他说明

### 已对齐设计决策清单（推敲摘要）

1. **选题**：试卷第 11 题（三圆 + 直线弦长多选），自 19 题中选出；兼顾难度与「抽象 → 可见动画」契合度。
2. **动画定位**：**选项场景索引**，不是解题片。
3. **参数**：\(k\) 与 \(b\) 均在前奏与正文中出场。
4. **弦长呈现**：三色加粗弦 + 长短变化；**无数字**。
5. **成片结构**：**C 方案** — 前奏 ~10 s（镜 1 定 \(b\) 扫 \(k\)；镜 2 定 \(k\) 扫 \(b\)）+ 正文四段式 A→B→C→D。
6. **A 段**：多 \(k\) 快切，三圆均有弦。
7. **B 段**：三色弦视觉等长定格/慢闪。
8. **C 段**：**B 方案** — 快切 + **等长淡色折线**（线不同、总长同、暗示 >3 条）。
9. **D 段**：\(b=0\)，扫 \(k\) 停在总长视觉峰值。
10. **镜 3 组合扫**（\(k\) 全扫 + \(b\) 跟信封线，起止相切帧）：降为 C 段素材能力，不作独立长段落。
11. **发布**：**Live Photo（`.pvt`）** 为 v1 唯一主产物（推敲选项 A）。
12. **悬念**：答案与判题留给文案/评论区。

### 四选项与画面锚点（正文索引）

| 选项 | 题面语义（简述） | 动画锚点 |
|------|------------------|----------|
| **A** | \(k\) 可取任意实数 | 多个斜率下直线均截出三色弦 |
| **B** | 恰有 3 条直线使 \(s_1=s_2=s_3\) | 三色弦**等长**的典型姿态（不枚举「3 条」） |
| **C** | 使 \(s_1+s_2+s_3=3\) 的直线超过 3 条 | 不同直线 + 淡折线**总长一致** + 多次快切 |
| **D** | \(b=0\) 时 \(\sum s_i\) 的最大值为 \(\frac{2\sqrt{21}}{3}\) | 过原点直线在峰值倾角下的三色弦（**不显示** \(\frac{2\sqrt{21}}{3}\)） |
