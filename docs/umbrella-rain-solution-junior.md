## （1）点 C 到地面的距离

**已知**：伞面水平，`OG ⟂ AC`，`OG = 0.45 m`，手握点 `G` 离地 `1.35 m`，`O` 为 `AC` 中点。

**分析**：`OG` 竖直向上（与 `NP` 共线），故 `O` 在 `G` 正上方 `0.45 m` 处。

```
OY = 1.35 + 0.45 = 1.80
```

（单位：m）伞面水平，`C` 与 `O` 等高，故 **C 到地面距离为 1.80 m**。

**程序验算**：`c_height_m = 1.80`

## （2）图 1：`theta = 72°`，求淋湿长度 `PK`

**已知**：雨线与地面夹角 `theta = 72°`，雨线向左下；过伞右缘 `C` 的雨线交身体前侧 `NP` 于 `K`。

**作图**：过 `C` 作雨线方向直线，交竖直线 `NP`（身体厚度 `0.2 m`）于 `K`。

在直角三角形中，`C` 比 `N` 侧水平多出 `0.5 m`（半伞宽），竖直落差：

```
PK = OY - 0.5 * tan(72°) ≈ 1.8 - 0.5 * 3.08 = 0.26
```

（单位：m；题给 `tan(72°) ≈ 3.08`）

**答：淋湿部分长约 0.26 m**。

**程序验算**：`pk_theta_72_m ≈ 0.26`

## （2）图 2：`theta = 60°`，前伸 `EG = x`，求 `y = f(x)`

手臂前伸后，伞仍水平，`C` 在 `(0.7 + x, 1.8)`。

同理，

```
y(x) = PK = 1.8 - tan(60°) * (0.5 + x) = 1.8 - sqrt(3) * (0.5 + x)
```

（若 `y < 0` 取 `0`；若 `y > 1.6` 取 `1.6`。）

**头部不淋（按题意左侧判定）**：看“过左端点 `A` 的雨线”和头顶线段 `MN` 的关系。  
设这条雨线与 `MN` 交于 `H`。若 `H` 在 `M` 的左侧或恰好是 `M`，则头顶线段 `MN` 不被雨线穿过，头部不淋。  
所以临界条件是 `H` 与 `M` 重合（`x_H = 0`）。

```
x_A = x - 0.3
```

一步步化简：

```
x_H = x_A + (1.6 - 1.8) / tan(60°)
```

```
x_H = x - 0.3 - 0.2 / sqrt(3)
```

```
头部不淋  <=>  x_H <= 0
```

```
x <= 0.3 + 0.2 / sqrt(3) ≈ 0.415
```

与题目约束 `0 <= x <= 0.5` 取交集，得到：

```
0 <= x <= 0.415
```

所以并不是“无解”，而是 **当前伸不超过约 `0.415 m` 时，头部不淋湿**。

**程序验算**：`y(0) ≈ 0.93 m`，`head_dry = true`（存在可行区间）

## （3）图 3：旋转伞面至 `AC ⟂` 雨线，能否全身不淋？（初中思路）

将伞绕 `G` 顺时针转至伞面与雨线垂直。此时 `AC` 方向与雨线方向垂直，可改变过 `C` 的雨线在身体前的截距。

**结论**：可以。在 `theta = 60°` 下，存在前伸量 `EG` 使 `PK = 0`。

用“临界法”判断最小前伸量（初中常用）：

- 若过 `C` 的边界雨线在 `P` 上方截到 `NP`，则脚部会淋湿；
- 若边界雨线恰好过 `P`，就是“刚好全身不淋”的临界；
- 若边界雨线落到 `P` 以下，则全身都不淋。

所以最小 `EG` 一定满足临界条件：`K` 与 `P` 重合，也就是 `PK = 0`。  
把这个条件代入图 3 的几何关系（与第二问同样是“直角三角形边比/相似三角形”的线性关系）即可解得最小值：

```
EG_min ≈ 0.20, and 0 <= EG <= 0.5
```

（单位：m）

**答：能；最小前伸量约为 0.20 m。**

**程序验算**：`min_eg_m ≈ 0.20`
